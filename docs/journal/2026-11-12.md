### Car-select FPS (GPU) + GT3 deko lesson

Owner: splash/loading smoother on GPU build; car select ~0.5–1 FPS. Soft too slow to reach it.
Cause: WritebackDk `dkQueueWaitIdle` + full tex-cache drop on every GIF packet (UI = many TEX0 binds).
GT3-revisited [v0.6.0-deko](https://github.com/tomplayer07/GT3-revisited-switch/releases/tag/v0.6.0-deko) is a
native engine (not GS writeback), but the useful pattern is the same: keep textures GPU-resident, batch uploads,
fence/ring instead of idle-per-draw (`texture_upload_batch`, submission slots).

Applied here:
- Invalidate decoded/GPU tex cache only when `TransferCommits` / `ImageQwords` advance (real BITBLT/IMAGE).
- 16-slot pitch-linear texture ring; `WaitIdle` only when reclaiming a slot still in flight, or on SLM flush.
- No idle when EndFrame has nothing dirty to read back.
- Rebuilt/exported soft + `export/switch-gpu/` for device retest of car select.
